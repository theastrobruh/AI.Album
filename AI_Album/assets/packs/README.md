# Assets — Packs

This folder holds the cover images for the Mini-Store packs.

## Expected files

| Filename | Pack |
|---|---|
| `mockups.webp` | Pack #1 — Mock Ups |
| `tshirt.webp` | Pack #2 — T-shirt Design |
| `architecture.webp` | Pack #3 — Architecture & Environments |
| `igmodel.webp` | Pack #4 — IG Model |
| `influencer.webp` | Pack #5 — Digital Influencer |
| `allinone.webp` | Pack #6 — All in One |

## Format

Use **WebP** for the best quality-to-size ratio.  
Recommended dimensions: **800 × 1200 px** (2:3 aspect ratio matches the card layout).

> These images are excluded from version control via `.gitignore`.  
> Add your own cover images here before opening the app.
